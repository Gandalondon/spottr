# Spottr

A voice companion for ARC Raiders. Leave it open beside you, tap the mic, ask where the next quest step is, hear the answer.

## Install on the Pixel

1. On the Pixel, open the latest release of this repo and tap `spottr.apk`.
2. When Chrome asks, allow it to install unknown apps (switch on "Allow from this source", then go back).
3. Tap Install. If Play Protect warns that it doesn't recognise the developer, choose "Install anyway".
4. Open Spottr and allow the microphone the first time you tap the mic.

## What works in this build

- Tap-to-talk with Android's speech recognition, spoken answers with Android's text-to-speech.
- Quest step tracking: "I'm on Home to Roost, step 3", "done", "step 5".
- Blue Gate exits, hatches and enemy spawns, with the real MetaForge map, a star on the answer, zoom, recentre and whole-map buttons.
- Asks where you are only when an answer depends on it.
- Screen stays on while Spottr is open.

## Not yet

- "Hey Spottr" wake word (needs a custom-trained model).
- Maps other than Blue Gate.
- The map needs a connection; answers still work without one.

Game data and map imagery: MetaForge (metaforge.app/arc-raiders). Spottr is unofficial and not affiliated with Embark Studios.
